# 技术实现

本文说明「键鼠工厂」内部是怎么实现的：钩子、注入、调度、录制回放与界面。面向想了解原理或参与开发的读者；使用方式见 [README](../README.md)，功能方案的推演与落地记录见 [PLAN](PLAN.md)。

## 平台与整体思路

Windows x64，C# / .NET 8 WinForms。核心是一条「低级钩子采集 → 工作线程按时间轴调度 → `SendInput` 注入」的链路，连按、鼠标连点、轨迹回放三条业务共用这套底座，UI 只负责收集参数、开关引擎、轮询状态，不参与实时调度。

## 各模块实现

- **键盘钩子**：`SetWindowsHookEx(WH_KEYBOARD_LL)` 低级钩子，过滤自身注入事件防止自我触发。
- **鼠标钩子**：`SetWindowsHookEx(WH_MOUSE_LL)` 低级钩子（`LLMHF_INJECTED` 过滤自身注入的点击），触发时拦截原生点击由引擎统一注入。
- **按键模拟**：`SendInput` 扫描码方式发送（键盘）/ `MOUSEEVENTF_*` 标志（鼠标），兼容性最好。
- **连按 / 连点调度**：工作线程按 `Stopwatch` 维护每个目标的「下次到期时刻」，用完就阻塞在 `AutoResetEvent` 上——没人按键时零唤醒（实测 525 次/秒 → 0），按键/松手/停止时立即叫醒（唤醒延迟 ~0.03ms，比 1ms 轮询的 ~1ms 更快）；`timeBeginPeriod(1)` 也只在真有键要连按时申请，空闲时把系统计时精度还回去。
- **轨迹录制**：`WH_MOUSE_LL` 回调里只做「过滤 + 预分配列表 Add」，不写文件、不碰 UI，避免回调超时被系统静默摘钩；悬浮条矩形整块排除、两级时间/位移降噪。
- **轨迹回放**：独立高精度线程按录制时间轴重放；定位用 `MOUSEEVENTF_ABSOLUTE | VIRTUALDESK` 归一化到虚拟桌面，多屏负坐标与 125%/150% 缩放都和录制一致；相邻移动间隔 ≥32ms 且位移 ≥4px 时按 16ms 补点，点击按下/抬起至少保持 20ms；回放状态条挂 `WS_EX_TRANSPARENT | WS_EX_NOACTIVATE`，只显示不接鼠标，轨迹点过去也不会被它吞掉。等待同样不用轮询：线程睡到时间轴下一个点的到期时刻，轮与轮之间连 1ms 计时精度也还回去、最后 50ms 再提回来定点（实测间隔期唤醒约 700 次/秒 → 约 150 次/秒，剩余部分是回放状态条自身刷新），停止时立即叫醒。尾段采用 10ms 小步等待而不是一次等到底——系统调度偶尔会把单次长等待推迟几十毫秒，小步每醒一次重算剩余可立即补偿（实测最大迟到 38ms → 2ms）；10 轮总时长 13008ms → 13011ms 无漂移。
- **全局热键**：`RegisterHotKey` + `WM_HOTKEY` 消息。
- **自绘 UI**：全部控件（按钮、输入框、数字框、下拉框、复选框、滚动条、托盘）基于 GDI+ 手写。
